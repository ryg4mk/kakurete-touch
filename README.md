# ONE TAKE GAME #003 — かくれてタッチ！

スマートフォン縦画面向けの、見下ろし型「だるまさんがころんだ」ゲームです。外部ライブラリ・外部画像・外部音声・ビルド工程なしで動作します。

## 遊び方

- 画面左1/3をタップ：左斜め前へ1歩
- 画面中央1/3をタップ：真上へ1歩
- 画面右1/3をタップ：右斜め前へ1歩
- 鬼が後ろを向いている間に進み、木・岩・箱の後ろに表示される薄緑の安全地帯を利用します。
- 鬼がこちらを見ている間に移動すると即ゲームオーバーです。
- 鬼が見ている間、丸見えのまま停止していると発見ゲージが増え、満タンでゲームオーバーです。
- 鬼に接触すると自動でタッチ成功です。
- 鬼はときどきフェイントをします。
- 最速クリアタイムと、失敗時に最も鬼へ近づけた記録はブラウザの `localStorage` に保存されます。
- 音は初期状態でミュートです。左上の 🔇 / 🔊 ボタンで切り替えられます。

## ファイル

- `index.html`
- `style.css`
- `game.js`
- `README.md`

4ファイルを同じフォルダに置き、`index.html` を開けば遊べます。

## GitHub Pages への配置

1. GitHubリポジトリへ4ファイルをアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch** にします。
4. 公開するブランチ（例：`main`）と `/(root)` を選んで保存します。
5. 表示されたGitHub PagesのURLをスマートフォンまたはPCブラウザで開きます。

## 仕様メモ

- HTML / CSS / Vanilla JavaScript
- Canvas描画
- Web Audio APIによるコード生成効果音
- 固定縦画面、スマートフォン優先
- PCはマウス操作対応
- 外部依存なし
